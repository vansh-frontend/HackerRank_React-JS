# 📖 About

This repository contains my solutions to **HackerRank React.js** challenges.

The goal is to strengthen my understanding of:

- React Fundamentals
- Components
- JSX
- State Management
- Event Handling
- Forms
- Conditional Rendering
- Lists & Keys
- React Best Practices

Each solution is written using **React + Vite** with clean, readable, and maintainable code.

Clone the repository

```bash

```

Move into the project

```bash
cd hackerrank-reactjs-problems
```

Install dependencies

```bash
npm install
```

Start Development Server

```bash
npm run dev
```
